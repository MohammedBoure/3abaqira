# Excel Source Files Directory (`docs/excel_files/`)

This directory contains the original legacy Microsoft Excel workbooks used for center and daycare management.

## Directory Contents

| File | Purpose |
|------|---------|
| `center.xlsx` | Master workbook for the Training Center & Academy operations, comprising 30 worksheets covering course enrollments, competitions, coaching payroll, pricing, and treasury. |
| `rawda.xlsx` | Master workbook for the Kindergarten & Daycare operations, comprising 8 worksheets covering child subscriptions, daily cash drawer reconciliation, expense budgets, and cafeteria supplies. |
