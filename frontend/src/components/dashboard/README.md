# Dashboard Components

This directory contains dashboard section components showcasing the visual prototype interface.

## Files

- **`HeroBanner.jsx`**: Welcome banner with gradient glass finish, contextual branch badges, and quick action trigger buttons.
- **`MetricGrid.jsx`**: Grid container organizing key financial and operational counter cards across centers.
- **`MockDataGrid.jsx`**: Interactive table preview for Academy and Daycare students with live search filtering, status badges, and details modal triggers.
- **`CashDrawerOverview.jsx`**: Visual overview of cash session status, current drawer balance, and recent transaction log with glassmorphic cards.
- **`ProgramsOverview.jsx`**: Grid display of active educational and development programs, capacity progress bars, and schedule badges.
- **`PreviewModals.jsx`**: Presentation dialogs for student profiles, new registration mock forms, and cash register audit reports.
