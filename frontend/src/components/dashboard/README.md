# Dashboard & Module Components (`frontend/src/components/dashboard/`)

This directory contains the operational dashboard views, spreadsheet grids, and template interfaces for the 3abaqira Enterprise Platform.

## Files

- **`ExcelDataGrid.jsx`**: High-density Excel-like data grid engine featuring 26 columns, frozen/sticky panes (Index, Code, Name), column chooser with preset configurations, workbook sheet tabs synchronized with branch scope, interactive right-click context menu (`ContextMenu`) with TSV/JSON copy, cell copy, inline record inspection, quick-edit modal, and printable official receipt voucher modal (`backend/apis/students.py`).
- **`AnalyticsDashboard.jsx`**: Professional executive business intelligence and statistics dashboard designed without AI spectrum tropes (no purple glowing orbs/neon), featuring monthly cash flow velocity curves, program capacity meters, aging arrears distribution, direct branch comparison (Center vs. Rawda), and a comprehensive program financial pivot table.
- **`HeroBanner.jsx`**: High-density enterprise welcome banner with sharp architectural borders, official circular logo (`frontend/public/assets/branding/logo.webp`), active academic year badges, dynamic branch-scope indicator badges, database engine status, and primary action triggers.
- **`MetricGrid.jsx`**: High-density KPI grid container housing operational counters for enrolled students, live drawer liquidity, collection rate/active programs, and cafeteria logistics with dynamic branch-level reactivity (Center vs. Rawda vs. All) and defensive optional chaining (`labelAr`).
- **`CashDrawerOverview.jsx`**: Daily cash drawer and register ledger view with transaction tracking, voucher codes, and administrative deposit voucher triggers (`backend/apis/registers.py`).
- **`ProgramsOverview.jsx`**: Academic catalog and cohort capacity meters across Soroban, Daycare, Robotics, Quran, and Foreign Languages (`backend/apis/programs.py`).
- **`PayrollOverview.jsx`**: Ready template interface for HR, staff, and coach payroll calculations (base pay, session rates, gross wages, deductions, and net payout signoff) (`backend/apis/payroll.py`).
- **`ProvisionsOverview.jsx`**: Ready template interface for Daycare kitchen procurement, daily bread logs, meat and protein orders, and supplier receipts (`backend/apis/kitchen.py`).
- **`AcademicYearsView.jsx`**: Formal management interface for `backend/apis/academic_years.py` featuring active cycle spotlights, academic cycle date-range grids, atomic cycle activation (`/set-current`), cycle creation modal, and enrollment continuity metrics.
- **`BranchesView.jsx`**: Formal multi-tenant campus interface for `backend/apis/branches.py` featuring branch profiles (Center vs. Rawda), operational status toggle (`/status`), classroom allocations grid (`/classrooms`), room capacity/occupancy bars, and branch/room creation dialogs.
- **`AuditLogsView.jsx`**: Formal compliance interface for `backend/apis/audit.py` featuring system audit trail grids, event telemetry counters (INSERT/UPDATE/DELETE), filter ribbon (by table, action, actor, date), interactive before-and-after diff inspection modal, and manual audit recording form.
- **`AuthSecurityView.jsx`**: Formal security interface for `backend/apis/auth.py`, `backend/apis/security.py`, and `backend/apis/users.py` featuring current authenticated profile (`/me`), active JWT bearer token telemetry and expiry countdown, password change form (`/change-password`), staff user accounts directory, and RBAC role permissions matrix.
- **`InvoicesPaymentsView.jsx`**: Formal invoicing, installment management, and receipt ledger interface matching `backend/apis/invoices.py` and `backend/apis/payments.py` with overdue detection, cash/bank payments recording, right-click context menu (copy TSV, filter by student, quick installment payment), branch scope filtering, and voucher generation.
- **`BudgetsExpensesView.jsx`**: Operational expense management and cost variance control interface matching `backend/apis/budgets.py` and `backend/apis/expenses.py` with monthly budgeted allocations, category breakdowns, branch scope filtering, right-click context menu (copy TSV, quick filter by category/vendor), and new voucher logging.
- **`HandoversView.jsx`**: Cash custody and vault transfer interface matching `backend/apis/handovers.py` and `backend/apis/registers.py` with source drawer transfers, recipient signoffs, status tracking (PENDING/CONFIRMED), and transfer request creation.
- **`PricingPlansView.jsx`**: Academic fee structures, installment tariff configurations, and discount rule management matching `backend/apis/pricing_plans.py` with sibling, upfront cash, and annual discount rules.
- **`EnrollmentsView.jsx`**: Student academic contracts and payment obligation ledger matching `backend/apis/enrollments.py` with payment modes (INSTALLMENT, MONTHLY, CASH_UPFRONT) and invoice status tracking.
- **`GroupsLevelsView.jsx`**: Pedagogical curriculum groupings, levels hierarchy, and physical room capacity interface matching `backend/apis/groups.py`, `backend/apis/levels.py`, and `backend/apis/classrooms.py`.
- **`SchedulesSessionsView.jsx`**: Weekly recurring timetables, classroom clash prevention, and conducted sessions attendance ledger matching `backend/apis/schedules.py` and `backend/apis/sessions.py` with instructor wage calculation and student gamification points.
- **`CompetitionsView.jsx`**: Master events catalog, participant candidate registrations, and official voucher generation (CMP-BRANCH-YYYY-XXXXX) matching `backend/apis/competitions.py` with automatic cash register revenue sync.
- **`GuardiansView.jsx`**: Parents and guardians master directory matching `backend/apis/guardians.py` with primary and secondary contact coordinates, national identification (NIN), linked student wards inspection, and direct phone/WhatsApp actions.
- **`SystemHealthView.jsx`**: Live backend operational telemetry, database connection pool status, infrastructure summary, archive view status, and application metadata configuration (App Metadata) matching `backend/apis/system.py`.
- **`PreviewModals.jsx`**: Sharp modal dialogs for new student enrollment and daily cash register reconciliation audits.
- **`MockDataGrid.jsx`**: Standard table preview component.
