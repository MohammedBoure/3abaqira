# Center (Academic Academy & Bejaia Center) Components (`frontend/src/components/dashboard/center/`)

This directory contains the operational, pedagogical, and financial interfaces dedicated exclusively to the **Center branch (المركز الأكاديمي والتعليمي - مركز بجاية)** in strict conformance with Section 3 of `docs/frontend.md` and user specifications in `docs/3abaqira.md`.

## Architectural Modernizations Applied:
- **Maximized Vertical Space**: Removed bulky decorative headers in favor of top-bar Info `(i)` modals, compact `h-8` row heights, and dedicated internal KPI tabs.
- **Mouse Right-Click Interaction**: Rich context menus across all tabular data grids for inline status toggling, relational editing, receipt preview, copying summaries, and deletion.
- **Multi-Year Support**: High-level academic year switchers (`2024-2025`, `2025-2026`, `2026-2027`) across all financial, registry, and timetable registries.
- **Excel Replacement Config Tabs**: Custom configuration interfaces embedded directly inside timetable, payroll, and pricing views to customize dimensions, rates, and rules without external spreadsheets.
