# 3D Components

This directory contains 3D graphics components powered by Three.js and WebGL.

## Files

- **`InteractiveBackground.jsx`**: Ambient light-mode Three.js WebGL background rendering an understated, low-contrast architectural geometric structure (frosted icosahedron, delicate wireframe, thin orbital ring, and sparse micro-particles) designed as a non-distracting background element with gentle mouse parallax tracking.
