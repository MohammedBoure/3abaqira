# Layout Components (`frontend/src/components/layout/`)

This directory contains the application shell and navigation ribbon components.

## Files

- **`Navbar.jsx`**: Full-width, sharp sticky navigation bar featuring the brand logo, multi-tenant branch selector (`ALL` ⇄ `CENTER` ⇄ `RAWDA`), quick search input, language switcher, and module navigation tabs (`excel-grid`, `analytics`, `treasury`, `programs`, `payroll`, `provisions`).
