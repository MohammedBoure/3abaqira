# Layout Components (`frontend/src/components/layout/`)

This directory contains the application shell and navigation ribbon components adapted to the Spatial Knowledge Workspace Blue theme.

## Files

- **`Navbar.jsx`**: High-density enterprise utility header featuring sidebar toggle, circular official emblem (`frontend/public/assets/branding/logo.webp`), view breadcrumb trail with dynamic business module titles across all Rawda and Center interfaces, real-time search input with `Ctrl+K` keyboard shortcut badge, active branch scope indicator, system synchronization badge (`قاعدة البيانات: متزامنة`), and interactive user session badge displaying avatar initials, staff name, and role.
- **`Sidebar.jsx`**: Collapsible navigation ribbon featuring the mandatory fixed 2-state context switcher (Section 1.2: Rawda Kindergarten vs Academic Center), dynamically rebuilding the entire navigation tree into the 4 structured groups for each entity, plus a Super Admin comprehensive workspace drawer and user account session footer with an account switch button (`تبديل الحساب`).
