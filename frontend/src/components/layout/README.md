# Layout Components (`frontend/src/components/layout/`)

This directory contains the application shell and navigation ribbon components adapted to the Spatial Knowledge Workspace Blue theme.

## Files

- **`Navbar.jsx`**: High-density utility header featuring sidebar toggle, view breadcrumb trail with dynamic module names for both spreadsheet sheets and backend API interfaces (`academic-years`, `branches`, `audit-trail`, `auth-security`), real-time search input with `Ctrl+K` keyboard shortcut badge, active branch indicator, database sync status indicator, language toggle (`العربية` ⇄ `Français`), and quick-action buttons ("الصندوق اليومي", "تسجيل جديد").
- **`Sidebar.jsx`**: Collapsible two-state sidebar featuring the signature geometric asterisk emblem (`.brand-symbol`), active workspace card (`3A`), dual module groupings (`MODULES & SHEETS` + `SYSTEM APIS & CONTROL`), branch scope switcher (`ALL`, `CENTER`, `RAWDA`), and local database health card with user role badge.
