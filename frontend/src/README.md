# Frontend Source Layer (`frontend/src/`)

This directory contains the root React components, styling systems, mock datasets, and layout orchestration for the 3abaqira Enterprise visual prototype.

## Directory Contents

| File / Folder | Purpose |
| :--- | :--- |

| [styles/](file:///C:/Users/moham/Desktop/3abaqira/frontend/src/styles) | Centralized CSS token layers for the sharp architectural palette, Excel grid styling, and swappable typography variables. |
