# Frontend Source Layer (`frontend/src/`)

This directory contains the root React components, styling systems, mock datasets, and layout orchestration for the 3abaqira Enterprise visual prototype.

## Directory Contents

| File / Folder | Purpose |
| :--- | :--- |
| [App.jsx](file:///C:/Users/moham/Desktop/3abaqira/frontend/src/App.jsx) | Main React component integrating the 3D WebGL background, navbar, hero banner, KPI grid, student roster, and preview modal dialogs. |
| [main.jsx](file:///C:/Users/moham/Desktop/3abaqira/frontend/src/main.jsx) | DOM entrypoint mounting the application with `ReactDOM.createRoot` and loading global styles. |
| [components/](file:///C:/Users/moham/Desktop/3abaqira/frontend/src/components) | Reusable UI components categorized into 3D, branding, common glassmorphic widgets, dashboard modules, and navigation layouts. |
| [mock/](file:///C:/Users/moham/Desktop/3abaqira/frontend/src/mock) | Static mock datasets for students, cash register movements, academic programs, and KPI metrics. |
| [styles/](file:///C:/Users/moham/Desktop/3abaqira/frontend/src/styles) | Centralized CSS token layers for the primary blue palette, glassmorphic surface effects, and swappable typography variables. |
